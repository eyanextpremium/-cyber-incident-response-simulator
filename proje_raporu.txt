Siber Olay Müdahale Simülatörü – Proje Raporu

1. Proje Özeti

Bu proje, Rust tabanlı, SQLite destekli, Axum REST API katmanı ve vanilla JavaScript/CSS arayüzü kullanan bir Siber Olay Müdahale Simülatörü uygulamasıdır. Amaç, SOC analisti, güvenlik operasyonları uzmanı ve eğitim alanı kullanıcılarına gerçekçi saldırı senaryoları üzerinden olay tespiti, olay müdahalesi, soruşturma, delil toplama, içeriden/haricen müdahale ve iyileştirme akışları öğreterek güvenlik operasyon merkezini (SOC) uygulamalı olarak öğretmektir.

Proje, kısmen eğitim/uygulama ortamı, kısmen ürün prototipi niteliğindedir. Kullanıcılar senaryo oluşturabilir, olay akışı izleyebilir, olaylar, uyarılar, etkinlik akışı, deliller, müdahale eylemleri, skorlar ve TL;DR sonuç raporları üretebilir. Arayüz tarafı fronted/ klasörü altında HTML, CSS ve JavaScript dosyalarıyla sağlanır. Backend ise Rust, Axum, Tokio, Rusqlite, serde ve tracing altyapısıyla çalışır.

Teknoloji yığını:
- Rust 2021
- Axum 0.7 web API
- Tokio async runtime
- rusqlite SQLite erişimi
- Argon2, HMAC/SHA1, SHA256, Base64, UUID, serde, serde_json
- tower-http CORS ve static file servisleri
- Vanilla HTML/CSS/JS arayüzü
- SQLite veritabanı

2. Mimari

Proje, katmanlı bir mimariye sahiptir:

- src/main.rs: Uygulamanın giriş noktasıdır. .env dosyasını yükler, logging başlatır, settings yükler, DB kurar, rule/scoring config yükler, seed assets ve app state kurar, UDP syslog dinleyicisi başlatır, scenario tick loop ve router oluşturur.

- src/lib.rs: Kütüphane giriş noktası ve modüllerin `pub mod` tanımlarını içerir.

- src/api/: HTTP API katmanı.
  - handlers.rs: tüm REST route handler’ları.
  - middleware.rs: request logger, güvenlik başlıkları, IP lockdown, token doğrulama ve IP başına istek sınırlama mantığı.
  - routes.rs: /api altında router oluşturur, route ve middleware katmanları uygular.
  - ws.rs: SSE ve WebSocket event stream sağlayıcısı.
  - errors.rs: error mapping / custom error tipleri.

- src/database/: Veritabanı şeması ve repository.
  - connection.rs: tablo şeması ve init_database/init_in_memory.
  - repository.rs: veri erişim işlevleri kullanıcı, olay, oturum, olay, senaryo, skor, delil, süre metodları.
  - queries.rs: SQL stringleri ve prepare edilmiş sorgular.

- src/models/: Veritabanı model veri yapıları.
  - user.rs: User/UserDbRecord
  - assets.rs, evidence.rs, network.rs, farklı sistem nesneleri

- src/detection/: Detections engine katmanı.
  - correlation.rs: olay korelasyonu
  - engine.rs: olay testi ve alarm üretimi
  - ioc.rs: IOC eşleştirme
  - severity.rs: kritik/seviyeye göre sınıflandırma
  - rule.rs: detection rule tanımı

- src/audit/: Kendi kendine güvenlik/uygulama denetim ve tarama.
  - engine.rs: denetim akışı
  - scanner.rs: tarama kuralları
  - attacks.rs: saldırı testleri
  - report.rs: güvenlik denetim raporları

- src/incident/: Olay yönetimi, incident lifecycle.

- src/investigation/: Timeline, delil, olay zinciri ve soruşturma motoru.

- src/response/: İçerme, eradikasyon, geri kazanım, kontaminasyon akışları.

- src/scoring/: Skorlama metrikleri ve düşüş/medyan/rank metrik birimi.

- src/scenarios/: Senaryo yükleyicisi, senaryo türleri ve scenario generator.

- src/simulation/: AppState, SimulationEngine, session başlatma, çevrimiçi simülasyon.

- src/utils/: Security, validation, ids, time ve helper fonksiyonları.

- src/config/: settings/env/detection/scoring config loader.

- fronted/: ön yüz içeriği. HTML/CSS/JS ayrılmış.

5. Güvenlik Katmanları

Güvenlik katmanları mevcut kodda çeşitli düzeylerde bulunur:

- Argon2id hash: hash_password fonksiyonunda Argon2id kullanımı. Password verify path: Argon2id verify.
- XSS HTML encoding: html_encode() ve html_decode() işlevi.
- Token-based auth: generate_token/parse_token.
- TOTP: HMAC-SHA1 dynamically truncated, secret stored encrypted.
- Encryption of TOTP secret and user data fields via encrypt_field/decrypt_field.
- IP ban middleware: `Repository::is_ip_banned`, banned_ips table.
- Request logging and security headers: X-Content-Type-Options, X-Frame-Options, X-XSS-Protection, Referrer-Policy, CSP.
- Request rate limiting: `HashMap<String, VecDeque<Instant>>` inside middleware. dedications.
- Input validation: validate_session_id and sanitize_input.
- Register route disabled.
- Data listing through `Repository` with exceptions. Not all endpoints fully auth-protected because route stack order is half-wired.
- Avoiding hardcoded credentials in login route through environment login fallback for `ADMIN_USERNAME`/`ADMIN_PASSWORD`.

10. Eksikler ve Teknik Borç

- Yeni admin bootstrap için `.env` örnek dosyasına güvenli kullanım eklenmeli.
- Kayıt endpoint’i sistemi ruhsatlı yönetici dışında kullanılmamalı; iyileştirme için `register_user()` handler sadece admin role aware control should be separated.
- Auth middleware layer currently commented out in route stack. Need enable through correct Axum type-safe from_fn or layer chaining.
- Rate limiting in middleware uses `OnceLock<HashMap<...>>` and is not persisted across process restart.
- TOTP implementation uses `hmac` but may need dynamic counter/truncation and secret decode verification tests. 
- Encrypt/decrypt field logic uses a SHA-256 hash stream in the derived key chain. Strong enough but non-standard for production; should use a real KMS/AES key vault.
- Security modules have partial compatibility issues with `auth_middleware` and route layering; multiple layers in `middleware::from_fn` need to be consistent.
- `main.rs` background simulation tick loop is embedded and long-lived; route-level task should be isolated into dedicated scheduler.

12. Genel Değerlendirme

Güçlü yönler:
- Rust ve Axum kullanarak performans, güvenlik ve sağlam modüler yapı.
- Zengin veri modeli, güvenlik ve self-audit altyapısı.
- Frontend ve backend ayrımı net.
- MITRE mapping ve senaryo üretimi güçlü eğitim değeri.
- Test temel işlevleri var.

Zayıf yönler:
- Auth middleware layer integration currently incomplete or commented.
- Çoğu route mutation and security enforcement in middleware not consistently wired.
- .env bootstrap value handling should be formalized.
- Kayıt endpoint kapatıldı fakat güvenlik kuralı daha yanıltıcı. 
- Static files and UI code not fully shielded from injection by HTML context. 
- Generated database is not in the repo. Behaves as local simulation. 

Portföy değeri:
- Eğitim ve simülasyon platformu olarak etkili.
- Gelişmiş güvenlik operasyonları ve MITRE ATT&CK eğitim değeri.var.
- Uygulama, bir girişim/prototip/yaşlanabilir LOB güvenlik eğitimi için uygun.
